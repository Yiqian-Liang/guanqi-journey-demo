# 古籍逐字逐句研读台账

建立日期：2026-10-02。

这里把“找到资料”“OCR 完成”“读过原文”“可以转成玩法”分成四件事。只有完成影印页核对、句读、关键词辨义、注家意见和玩法边界，才记为“已精读”。

## 完成标准

每一条原文都要留下：

1. 影印本 PDF 页码及篇章位置。
2. 保留原字形的转录；疑字不硬改，记为 `[疑]` 或 `[缺]`。
3. 句读和关键词义；不能只写一段现代概述。
4. 正文与后世注文分开，不能把注家的解释倒灌成原文。
5. 版本异文、转录错误和无法确定处。
6. 可用于游戏的结构、只能作为叙事意象的内容、不得包装为现实结论的内容。

OCR 只用于找页和生成待校稿。竖排古籍中把“陰而至靈”一类文字识坏的情况很多，因此 OCR 文本不计为阅读成果。

逐页索引命令：`python3 research/close-reading/ocr_scans.py <PDF> <输出目录>`。每页文件都带有“必须回看影印页”的警告，脚本可中断后续跑。

## 对读底本

- 影印本是字形、篇次与页码依据。
- 维基文库转录只作检索和初校，不自动视为正确版本。
- 已核出会改变文义的误录包括“土形气形/土形气行”“无光发新/天光发新”；因此未经原页核对的电子文本不计入完成数。
- 外、杂篇又核出“负峙/负扆”“支葬其额/支葬其巅”“嫉生/嫉主”等误录；杂篇末段的注家还明确质疑部分方位、择日文字为后人附会。
- 《滴天髓》正文与《滴天髓阐微》的任氏注文、命例必须分层记录。
- 《子平真诠》不同版本的篇数、篇名和后加评注必须先辨明，再比较观点。

## 玩法采用门槛

只有满足以下条件的结论才能进入正式关卡：

- 能指出原文和篇章，不用网络文章的二手口号代替。
- 能说明这是正文、某家注文，还是游戏改编。
- 至少在同一书的上下文中没有自相矛盾。
- 不把墓葬、血缘感应、祸福预测等传统信念宣传成可验证事实。
- 玩家能从画面反馈理解因果，不需要先相信术数结论。

未达到门槛的内容可以留在研究笔记，不能进入教程文案。
