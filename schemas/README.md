# 局部结构校验

`chart.schema.json`校验字段和六十干支成员，跨柱关系仍由业务函数校验；`selection.schema.json`校验四个索引。`save.schema.json`是部分参考结构，事件/回执记录与origin细节并未全部展开。

所有schema为本地文件；`$id`的`.invalid`网址是标识符，不需要联网。真实存档导入必须实现完整类型的运行时校验，再做有限数值、ID、资源、权限、版本、承诺、时钟与位置语义检查。不得将此处通过当成游戏存档安全证明。

`fixtures/save_v4_minimal.json`为人工构造的零进度示例，不是从已运行游戏导出的存档。行脚客身份可存在于存档但实体在符合出现条件前不得显示。
