# 《观气行旅》实现状态

## 当前交付

- `guanqi-game/` 是可直接运行的单人浏览器游戏；Three.js 0.186.0 已随项目保存，不依赖 CDN。
- 默认画面已改为原创低多边形 3D 越肩跟随场景，支持拖动镜头；2D 全图保留为可切换的辅助视角。
- 创建页默认只显示随机与直接开始，复杂命盘选项折叠为可选；开场先运行六步学徒教学，再进入六步送信任务。
- 学徒教学在同一 3D 空间中呈现风路、屏风、灯焰、光路与桥台，完整流程为“观察异常→试摆与撤回→稳定灯火→景门显路→开门启桥→实际过桥”。
- 每一步只显示当前需要的场景操作，并提供三级可选提示；错误摆法直接显示失败原因，不扣资源、不回滚剧情。
- 开场、雾村、旧渠、药圃、渡口、结尾和教学总结共七组剧情对白已接入实际进度，使用原创对话头像。
- 创建页实现随机、自主定制、年柱/月支/日柱/时支锁定、日主筛选、三模板、GQ1 导入导出；随机使用 `gq-structural-mulberry32-v1`。
- 命盘面板改为四柱纵列表格，直接展示十神、干支、藏干、纳音、地势、空亡与神煞；并明确标注游戏结构盘不推算公历、真太阳时或大运。
- 15 个五行法式均已登记并接入实际场景对象；5 个开局法式与 10 个手记法式分开解锁，无效操作不扣灵力。
- 水、风、识路三条主线均需实际观察和处理环境；峡谷有藤桥、踏石、稳坡三种可选近路。
- 四位 NPC 有按时辰变化的位置、就地帮助、邀请条件、两时辰短约、安全点离队、最多两人同行和有方向十神协作。
- 6 个神煞事件家族与 6 个辅助类型分支接入回访流程；必要内容均有普通探索替代。
- 存档使用 current/previous 双代际、校验和、1 MiB 导入上限；可迁移本项目上一版浏览器存档并明确标记未知创建来源。
- 越肩场景以 Three.js 渲染山体、村屋、道路、水渠、地标、雾效、角色、NPC 与动态目标；原创 2D 场景底图用于辅助地图视角。

## 边界

- 尚未完成随机/自选 × 三路线共六次完整人工通关矩阵，也没有真人趣味性与长期平衡结论。
- 当前只能证明流程可操作、因果反馈可见；“不熟悉术数的真人能否复述规则并迁移到新题”仍需真实用户试玩，自动化和开发者自测不能替代。
- 旧浏览器原型档可迁移；设计契约中的所有 schema 1–3 外部存档形状尚未逐一接入生产导入器。
- 真人 2–3 人联网仍属于独立 `COOP-1`，本单人交付不冒称已联网。
- 未做正式性能基准或最终骨骼动画；当前 3D 角色使用原创低多边形几何体，重点完成镜头、空间与任务可读性。
- 命盘仍是可复现的游戏结构生成，不接受真实出生日期并计算历法、真太阳时或大运，界面不冒充专业命理排盘结果。
